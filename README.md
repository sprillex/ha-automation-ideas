# Home Assistant Local Automation Suggester

A lightweight, zero-AI, zero-YAML automation recommender and blueprint collection.

## 1. Import Blueprint (One-Click)

Click the badge below to import the starter automation template directly into your Home Assistant:

[![Open your Home Assistant instance and show the blueprint import dialog with a specific blueprint pre-filled.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fgithub.com%2F<YOUR_USERNAME>%2Fha-automation-ideas%2Fblob%2Fmain%2Fblueprints%2Fautomation_suggester.yaml)

### Manual UI Import
1. In Home Assistant, go to **Settings** > **Automations & Scenes** > **Blueprints**.
2. Click **Import Blueprint** (bottom right).
3. Paste:
   `https://github.com/<YOUR_USERNAME>/ha-automation-ideas/blob/main/blueprints/automation_suggester.yaml`
4. Click **Preview** and then **Import**.

---

## 2. Dashboard Browser (Zero YAML)

To embed the interactive catalog inside Home Assistant:
1. In your Home Assistant Dashboard, click the three dots in the top right > **Edit Dashboard**.
2. Click **Add Card** > select **Webpage**.
3. Set the URL to: `https://<YOUR_USERNAME>.github.io/ha-automation-ideas/`
